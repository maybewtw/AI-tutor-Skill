# AI Tutor Skill

> 一个面向 AI 初学者、传统平台产品经理和 AI 应用从业者的、基于权威来源与持续练习的 AI 学习教练。

## 项目简介

AI Tutor 是一个用于 Codex 的结构化学习 skill。它的目标不是一次性回答某个 AI 概念，而是帮助学习者建立从底层原理到应用框架、再到 AI 产品实践的连续知识体系。

它会根据学习者的角色、基础、目标和回答表现，动态选择学习路径、调整教学深度、设计练习，并持续识别尚未解决的误解。

项目覆盖的学习范围包括：

```text
AI 基础
→ 机器学习与深度学习
→ Embedding、Attention 与 Transformer
→ LLM 与推理
→ RAG、Agent、Workflow、Harness、MCP
→ 评测、可靠性、安全与权限
→ AI 产品和平台架构
```

## 核心能力

### 系统化课程导航

按照知识依赖关系组织课程，而不是孤立解释术语。对于高重要性、高依赖的主题，先给出全局地图，再补充必要的底层机制。

### 双路径教学

- **自底向上**：前置知识 → 直觉 → 局部机制 → 完整技术 → 系统作用 → 产品含义
- **自顶向下**：用户问题 → 产品目标 → 系统架构 → 关键组件 → 技术权衡 → 评估与决策
- **双轨学习**：先建立宏观地图，再针对关键依赖进行底层拆解

### 诊断式与适应式教学

每个重要主题都遵循：

```text
诊断已有理解
→ 设定本轮目标
→ 最小必要讲解
→ 让学习者先作答
→ 针对误解反馈
→ 新案例练习
→ 迁移到产品决策
→ 总结与复习安排
```

它不会仅根据用户自评判断“已经学会”，而是通过解释、比较、应用、失败分析和迁移题观察真实理解。

### 多层学习深度

同一概念可以分别面向：

- AI 初学者：少术语、重直觉和产品案例
- 产品经理：重用户价值、系统边界、质量、成本和风险
- AI 应用从业者：重架构、工具、数据、延迟、评估和工程权衡

### 来源分级与不确定性管理

优先使用论文、标准、大学课程、官方模型和框架文档；用高质量二手资料补充直觉和实践。对快速变化的模型、API、价格和框架行为，要求重新核验原始来源，并区分：

```text
事实 / 推断 / 假设 / 开放问题
```

### Agent 与 AI 产品视角

学习技术时同步回答：

- 它解决什么用户问题？
- 瓶颈在模型、数据、检索、工作流还是体验？
- 出错的成本是什么？
- 哪些动作需要人工确认？
- 应该测量质量、成本、延迟还是业务结果？
- 这是一个功能、工作流，还是可复用的平台能力？

## 适合谁

- 希望系统学习 AI 的传统平台产品经理
- AI 产品经理和解决方案设计者
- 刚开始接触 LLM、RAG、Agent 的学习者
- 需要把技术概念转化为产品判断的团队成员
- 希望建立长期 AI 学习路径，而不是只查单个术语的人

## 项目边界

AI Tutor 是教学 skill，不是一个独立的 AI Tutor 应用。它不默认部署服务、调用用户私有数据或替用户做高风险决定；它负责组织学习、检验理解、引用资料和帮助形成产品判断。

它支持：

- AI 基础、LLM、RAG、Agent、Harness 与 AI 产品架构学习
- 自底向上、自顶向下和双轨学习路径
- 诊断题、练习、迁移题和阶段性复习
- 基于权威来源的解释、引用和不确定性标注
- State、Checkpoint、学习进度与掌握度记录

## 上传到 GitHub

1. 在 GitHub 创建一个空仓库，例如 `ai-tutor-skill`。
2. 打开本文件夹，选择全部文件和文件夹。
3. 将它们拖到 GitHub 仓库的上传页面。
4. 点击 **Commit changes**。

上传后请确认 `SKILL.md` 位于仓库根目录，而不是多套一层文件夹。

## 在 Codex 中安装

在 skill 安装入口填写：

```text
你的用户名/ai-tutor-skill
```

安装后新建任务，输入：

```text
$ai-tutor
```

## 本知识库的来源策略

公开包保留了学习路径、来源索引和原始链接，不默认重新分发厂商网页或 PDF 的完整副本。涉及具体版本、价格和 API 行为时，应打开 `knowledge-base/INDEX.md` 中的原始来源重新核验。
