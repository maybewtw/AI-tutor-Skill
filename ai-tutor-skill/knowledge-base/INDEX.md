# AI Tutor 来源索引

**公开包快照日期：** 2026-08-28  
**优先时间范围：** 最近两年；涉及当前版本时必须重新打开原始来源核验。

本公开包不默认重新分发厂商网页或 PDF 的完整副本，只保留来源、用途和原始链接。来源用于学习导航，不应替代原始文档的许可证和版本检查。

## 来源分级

1. **一级：** 论文、标准、大学课程、官方模型或框架文档
2. **二级：** 有明确作者、引用和可复现实例的课程或技术教程
3. **三级：** 工程博客、案例和复盘，用于理解实践权衡
4. **发现用：** 社交媒体、无来源摘要和模型生成内容，不作为关键结论依据

## 核验规则

- 先定义要验证的学习目标，再选择来源。
- 关键结论优先使用一级来源，并尽量交叉核验。
- 记录发布日期、检索日期、版本和适用范围。
- 把事实、推断、假设和开放问题分开。
- 对价格、API 行为、模型能力和框架特性重新访问原始链接。
- 发现来源冲突时，记录冲突原因，不要静默选择一方。
